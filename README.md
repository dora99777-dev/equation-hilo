# 等式高低

用數字牌和 + − ÷ × √ 組出最接近 20 或 1 的算式，和五位電腦玩家對戰 9 局的單人網頁撲克遊戲。

- 直接用瀏覽器打開 `index.html` 就能玩，不需要安裝或登入。
- 開啟 GitHub Pages 後，網址為 `https://<帳號>.github.io/<repo 名稱>/`。

## 規則摘要
- 牌組 52 張：數字 0–10（金 > 銀 > 銅 > 黑 四色）共 44 張、√ 4 張、× 4 張；每人起手有 + − ÷。
- 每局：底注 1 → 1 張暗牌 → 2 張公開牌 → 第一輪下注 → 1 張公開牌 → 最後下注 → 輪流宣告「大 / 小 / Swing」並排出算式。
- 所有牌都要用到，沒有括號，先乘除後加減；√ 只能用在一個數字上。
- 最接近 20（大）或 1（小）的人贏；Swing 要兩邊都贏才算。底池由贏家平分，餘數由荷官沒收。
- 起始籌碼 30，共 9 局，籌碼歸零淘汰，最後以籌碼數排名。

此版本為原始版（Original，v2）。
