# 等式高低

用數字牌和 + − ÷ × √ 組出最接近 20 或 1 的算式的網頁撲克遊戲。不用安裝、不用登入，手機和電腦都能玩。

**線上遊玩：** https://dora99777-dev.github.io/equation-hilo/

## 檔案

| 檔案 | 內容 |
|---|---|
| `index.html` | 遊戲大廳：單人、繼續上一場、開房間、加入房間 |
| `single.html` | 單人模式（原始版 + 每局結束自動存檔在瀏覽器） |
| `multi.html` | 多人連線（PeerJS，房主的瀏覽器擔任荷官） |
| `original/index.html` | 原始版，保留不動 |
| `src/` | 多人版的原始碼片段；改完執行 `python3 src/build.py` 重新產生 `multi.html` |

## 規則摘要
- 牌組 52 張：數字 0–10（金 > 銀 > 銅 > 黑 四色）共 44 張、√ 4 張、× 4 張；每人起手有 + − ÷。
- 每局：底注 1 → 1 張暗牌 → 2 張公開牌 → 第一輪下注 → 1 張公開牌 → 最後下注 → 輪流秘密宣告「大 / 小 / Swing」並排出算式 → 全部宣告完再依序公布（原始版為宣告當下公開）。
- 抽到 √ 可再補一張；抽到 × 要交出一張 + − × 再補數字牌；第二張符號牌一律丟棄。
- 所有牌都要用到，沒有括號，先乘除後加減；√ 只能用在一個數字上。
- 最接近 20（大）或 1（小）的人贏；Swing 要兩邊都贏才算。底池由贏家平分，餘數由荷官沒收。
- 籌碼歸零淘汰，最後以籌碼數排名。

## 電腦難度
- 簡單：每次只試 10 種排法，常漏算。
- 普通：試 28 種排法，偶爾漏算。
- 困難：試全部排法（最多 576 種），每次都算到最好。
- 宣告時電腦會考慮押小的人數、後面還有幾人沒宣告，以及剛好排出 1 時最小的牌夠不夠小，避免全部擠去押小。原始版（`original/`）維持舊的電腦。

## 多人連線
- 房主開房時可設定：空位補電腦與電腦難度、行動計時（下注 / 排算式秒數）、起始籌碼、局數。
- 朋友用 4 碼房號或邀請連結加入，最多 6 位真人。
- 計時逾時：下注時不用跟注就過牌、要跟注就棄牌；排算式時已選邊而且排完就用目前算式宣告，否則視為棄牌。
- 斷線：當局自動棄牌、籌碼保留，用同一個瀏覽器重新進房可回到座位；房主離開則整桌結束。
- 連線透過 PeerJS 的免費公開伺服器牽線，部分公司 / 學校網路可能會擋，可改用手機熱點。
